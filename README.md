**Sessions 3–5 · Sep 15, 16, 17**

Your first real Java. By the end of this repo you will have written, broken, fixed, and run several programs, and you'll know what every piece of a Java file is for.

---

## How to work

1. **Fork** this repo → **Import to Replit** (Create → Import from GitHub)
2. Work through the exercises in order
3. **Run your code often.** Write 5 lines, run. Not 50 lines, run
4. **Commit as you go** — at least 3 commits, one per session minimum
5. Paste your fork's URL into Google Classroom

---

## Reminders

- Filename must match the public class name **exactly**, including capitals
- Read the **first** error message, not the last
- `Shift+Alt+F` in Replit auto-formats your code — do it before every commit
